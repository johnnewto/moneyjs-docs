# AGENTS.md

## What this repo is
`moneyjs-docs` is a standalone static documentation site for selected MoneyJS
notebooks. It renders **precomputed** solver results — no solver runs in the
browser. It reuses notebook publication components from the `moneyjs` repo,
included here as a **pinned git submodule** at `moneyjs/`.

This is a small pnpm workspace:
- `app/` — the Vite + React site (`@sfcr/docs-site`)
- `moneyjs/packages/{core,core-worker,notebook-core,web}` — workspace members
  (see `pnpm-workspace.yaml`); `pnpm install` resolves the full tree from the submodule

Node 22+ (see `.nvmrc`), `pnpm@10.8.0`. Run commands from the repo root.

## Default work location
Make changes in `app/`. Do **not** edit anything under `moneyjs/` from this repo
— it is a pinned submodule. Real changes belong upstream in the moneyjs repo
(johnnewto/moneyjs) and are absorbed here via a submodule bump (see below);
editing it locally risks silently lost work and pinning to an unpushed commit
that breaks CI and fresh clones. The submodule has its own `moneyjs/AGENTS.md`
that governs work *inside* moneyjs.

## Do not edit (generated / build output)
- `app/src/data/` — generated by the prebuild step and **gitignored**. Regenerate
  via `pnpm build:data`; never hand-edit.
- `app/dist/` — Vite build output (gitignored).

## Data build flow
`app/scripts/build-notebook-data.mjs` headlessly solves the YAML templates in
`app/notebooks/*.notebook.yaml` and emits JSON into `app/src/data/`. It runs
automatically via `predev`/`prebuild`. Notebooks are auto-discovered; a template
that fails to solve is **skipped** (logged), not fatal.

Notebook sources live in `app/notebooks/` (e.g. `sim`, `bmw`, `gl2-pc`, `io-pc`)
— this is separate from the submodule's pilot templates.

## Commands (run from repo root)
- `pnpm dev` — prebuild data, then start Vite
- `pnpm build` — prebuild + production build into `app/dist`
- `pnpm preview` — serve the production build
- `pnpm build:data` — regenerate `app/src/data` only
- `pnpm typecheck` — `tsc --noEmit`
- `pnpm test` — Vitest (`app/test/`)
- `pnpm menu` — interactive dev menu (`scripts/dev-menu.mjs`)

## Local dev against a live moneyjs clone (escape hatch)
Set `MONEYJS_ROOT=/path/to/moneyjs` to point the Vite alias and prebuild runtime
at a local clone. This does not change IDE/TypeScript types (those resolve to the
`moneyjs/` submodule) and CI never sets it.

## Updating the pinned submodule
Upstream moneyjs changes are not picked up automatically:
```bash
git submodule update --remote moneyjs
git add moneyjs && git commit -m "Bump moneyjs to <sha>"
pnpm build   # regenerate app/src/data from new source
```
The pinned commit must exist on `origin/main` of johnnewto/moneyjs for CI/fresh clones.

## Deployment
`.github/workflows/deploy.yml` builds with `VITE_BASE_PATH=/moneyjs-docs/` and
publishes `app/dist` to GitHub Pages.

## Conventions
- No ESLint/Prettier — rely on `pnpm typecheck` and Vitest.
- Prefer the smallest change that solves the task; avoid broad refactors.
- After substantive changes, validate with `pnpm typecheck` and `pnpm test`;
  if the data/build path is affected, run `pnpm build`.
